	Sorting Algorithms in Java
 Introduction

kani nga Java program gapakita sa tulo ka klase nga sorting algorithms: Bubble Sort, Selection Sort, ug Insertion Sort Ang tumong ani mao ang plastar sa mga number gikan sa pinakagamay hangtod sa pinakadako Gigamit ni ang tulo ka algorithms para makita kung unsaon nila plastar sa paryas nga mga number.

1. Bubble Sort

Ang Bubble Sort nagtrabaho pina Agi sa pagtandi sa duha ka magtapad nga number Kung ang una nga number mas dako kaysa ikaduha, magbaylo sila og plastar. Balik-balikon niya hangtod ang tanan nga number ma plastar na gikan sa gamay paingon sa dako.

 2. Selection Sort

Ang Selection Sort mangita sa pinakagamay nga number sa array. ayha dayun ni makit-an, ibutang niya ni sa unang plastar. Sunod, mangita na pud siya sa sunod nga pinakagamay nga number hangtod mahuman ang plastar.

3. Insertion Sort
Ang Insertion Sort nagplastar sa mga number usa-usa. Kuhaon niya ang usa ka number ug pangitaon ang saktong pwesto niini sa mga number nga nauna nang naplastar. Padayon kini hangtod mahuman ang tanan.

Differences Between the Three Algorithms
Ang Bubble Sort nagtan-aw ug nagtandi sa magtapad nga mga number. Ang Selection Sort mangita sa pinakagamay nga number ug ibutang kini sa saktong pwesto. Ang Insertion Sort magkuha og number ug isulod kini sa saktong lugar sa mga nauna nang naplastar nga number.

Lahi-lahi sila sa ilang pamaagi, pero parehas ang ilang resulta kay maplastar nila ang mga number gikan sa pinakagamay ngadto sa pinakadako.

Reflection Questions
1. How does each sorting algorithm arrange numbers? What makes their processes different?

Ang Bubble Sort magtandi sa magtapad nga mga number ug magbaylo kung kinahanglan. Ang Selection Sort mangita sa pinakagamay nga number ug ibutang kini sa hustong pwesto. Ang Insertion Sort magkuha og usa ka number ug isulod kini sa lugar nga angay niya. Nagkalahi sila sa proseso pero parehas ang ilang tumong.

2. Among the three sorting algorithms, which one do you think is the easiest to understand and implement? Why?

Para nako, ang Bubble Sort ang pinakasayon sabton ug buhaton kay simple ra ang proseso. Kinahanglan ra nako itandi ang duha ka magtapad nga number ug ibaylo ang ilang pwesto kung dili sakto ang pagkakaplastar.

3. If the numbers are already sorted, which algorithm do you think would perform better? Explain your answer based on how the algorithms work.

Para nako, ang Insertion Sort ang mas maayo kung daan nang naplastar ang mga number. Dili na kaayo siya kinahanglan magbalhin-balhin og number kay sakto na man ang ilang pwesto. Mas gamay ang iyang buhaton kung husto na daan ang pagkakaplastar.

4. What will happen if you add more numbers to your array? How might this affect the performance of each sorting algorithm?

Kung modaghan ang mga number sa array, modaghan pud ang trabaho sa sorting algorithms. Mas daghan na silang ikumpara ug plastaron. Ang Bubble Sort ug Selection Sort mahimong mas mohinay tungod kay daghan silag pagtandi. Ang Insertion Sort mahimong mas paspas kung hapit na naplastar ang mga number, pero mohinay gihapon kung daghan ang wala sa saktong pwesto.

5. As a future programmer, why is it important to understand different sorting algorithms instead of using just one?

Importante nga makasabot ko sa lain-laing sorting algorithms kay dili tanan parehas og performance. Isip future programmer, makatabang kini nako sa pagpili sa angay nga algorithm depende sa kadaghan sa data ug sa sitwasyon. Pinaagi niini, makahimo ko og mas maayo ug mas epektibo nga programa.
